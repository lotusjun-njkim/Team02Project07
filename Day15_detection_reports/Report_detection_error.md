## 1. Executive Summary

본 실험은 인천국제공항 출국심사 장 CCTV 영상 내 여객(Person) 객체를 실시간 추적하기 전, 매칭 알고리즘의 신뢰성을 검증하기 위해 수행되었습니다. 고정된 3개의 객체와 AI 모델이 예측한 4개의 후보 박스를 비교 분석하였습니다.

IoU 임계값 0.50 기준에서 **Precision 75.00%, Recall 100.00%**를 달성하여 매대 및 대기열 내 여객 누락 차단(Recall 100%) 능력은 완벽함을 확인했습니다만, 사람이 존재하지 않는 허공(배경)에 사각형 박스를 오탐지하는 **Background FP 오류가 1건 발생**하여, 혼잡도 통계 왜곡을 방지하기 위해 후속 공정에서 신뢰도 임계값(Confidence Threshold) 튜닝 및 NMS 후처리가 필수로 결합되어 다음 작업 예정

## 3. 평가 지표 및 결과

| 지표 | 값 | 산출 근거 |
| :--- | ---: | :--- |
| **TP** | 3 | 실제 대기 여객의 위치와 클래스가 일치하고 IoU $\ge$ 0.50 조건을 충족하여 매칭 성공 |
| **FP** | 1 | 실제 여객이 없는 빈 바닥 영역을 유령 물체로 오탐지하여 정답 매칭에 실패한 건수 |
| **FN** | 0 | 현장에 존재하는 실제 대기 여객을 놓치지 않고 AI가 모두 탐지해 냄 (누락 제로) |
| **Precision** | 75.00% | $TP / (TP + FP)$ $\rightarrow$ AI가 여객이라고 판단한 결과 중 진짜 여객의 비율 |
| **Recall** | 100.00% | $TP / (TP + FN)$ $\rightarrow$ 심사 장 내 실제 여객 중 AI가 빠뜨리지 않고 찾아낸 비율 |
| **F1-score** | 85.71% | $2TP / (2TP + FP + FN)$ $\rightarrow$ 관제 정확도 정밀도와 재현율의 조화평균 점수 |
| **mAP50** | 0.7812 | `checkpoint_comparison.csv` 및 `evaluate` 모듈 기반 IoU 임계값 0.50 기준 전반적 성능 |
| **mAP50-95** | 0.4635 | `ap_by_class_iou.csv` 내 IoU 0.50~0.95 구간 평균, 위치 정밀도를 고려한 엄격한 지표 |

**계산 검증:** 
- `TP + FP = 3 + 1 = 4` (총 예측 박스 수 4건과 일치)
- `TP + FN = 3 + 0 = 3` (총 정답 박스 수 3건과 일치)

### 오류 유형별 집계

| 오류 유형 | 건수 | 해석 |
| :--- | ---: | :--- |
| **Duplicate FP** | 0 | 이미 다른 높은 신뢰도의 예측 박스와 매칭이 완료된 정답 객체에 중복으로 연결을 시도하여 오탐지 처리된 건수 |
| **Background FP** | 1 | 현장의 실제 정답 객체들과 교집합 면적이 전혀 없거나, 무관한 배경 영역을 물체로 잘못 오인하여 탐지한 건수 |
| **Wrong Class FP** | 0 | 위치상 정답 객체와 포개어졌으나, 클래스 분류 정보가 불일치(예: 네모를 동그라미로 판정)하여 오답 처리된 건수 |
| **Loose Box FP** | 0 | 대상 객체의 클래스는 올바르게 맞추었으나, 박스가 너무 느슨하거나 어긋나 IoU 합격 임계값 기준 미달로 탈락한 건수 |
| **FN (Miss)** | 0 | 어떠한 예측 박스도 매칭되지 못하고 완전히 놓쳐버린 진짜 정답 객체의 총 수량 (미매칭 정답 이력 독립 계산) |
